# Endeavor Cleaning

The marketing site for Endeavor Cleaning, built with Next.js (App Router) and
deployed on Vercel.

## Prerequisites

- Node.js `>=22.13.0`

## Quick Start

```bash
npm install
npm run dev
```

## Useful Commands

- `npm run dev`: start local development
- `npm run build`: production build
- `npm start`: serve the production build locally
- `npm test`: build the site and verify the rendered homepage
- `npm run lint`: run ESLint

## Structure

- `app/`: pages, layout, and global styles
- `public/assets/`: images and fonts
- `tests/`: build-and-render smoke test
